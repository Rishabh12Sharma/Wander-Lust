# 🌍 Wander-Lust  
### ✈️ Explore • Discover • Travel  

---

## 🚀 Overview  

**Wander-Lust** is a full-stack travel listing web application inspired by platforms like Airbnb. It allows users to explore destinations, create listings, and share travel experiences.

The project is built using **Node.js, Express, MongoDB, and EJS** and follows the **MVC (Model-View-Controller)** architecture for scalability and maintainability.

---

## 🛠️ Tech Stack  

- **Backend:** Node.js, Express.js  
- **Database:** MongoDB (Mongoose)  
- **Frontend:** EJS, HTML, CSS  
- **Cloud Storage:** Cloudinary  
- **Validation:** Joi  
- **Architecture:** MVC  

---


---

## ⚙️ Features  

- Browse travel listings  
- Add, edit, and delete listings  
- Upload images using Cloudinary  
- Server-side validation using Joi  
- Clean and modular MVC architecture  
- Responsive user interface
